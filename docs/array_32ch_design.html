NECCS 32 路工业化声学阵列方案

生成时间：2026-04-19。当前版本按 4 × PCMD3180、32@48k 双 TDM16、16@192k 双 TDM8 输出，并新增“收音孔坐标 → 封装中心坐标”的动态转换。

32 物理麦4 × PCMD3180Inner8 + Transition8 + Outer16 声孔坐标 / 封装中心坐标双定义按 mic 粒度给出 PDM/TDM 连接

执行摘要

主方案继续采用工业化三尺度结构，但文档坐标体系升级成双定义：声学性能评估仍按收音孔坐标，EDA 下板按封装中心坐标。本页新增可调的封装角度、局部偏移和实时坐标表，硬件团队可以直接拿它推封装摆位。

与当前 16 路基线相比，主阵列的最大孔径从 81.66 mm 提升到 110.67 mm，最小间距压到 7.64 mm，空间混叠起点提升到 22.44 kHz。

  • 可承诺：0.3~8 m 的工业级检测 / 定位 / 成像主能力。
  • 可研究：20~40 kHz 高频精扫，40~80 kHz 近场热点确认。
  • 不应承诺：50~80 kHz 远距离高质量热图。
  • 16@192k 的前提：4 个 PCMD3180 都工作，每片只开 4 个核心 mic。

现有工程约束复述

  • 当前平台：STM32H743，后续目标迁移 STM32N6。
  • 当前链路：PDM mic → PCMD3180 → TDM/SAI → DMA → FFT → GCC/SRP-PHAT → 粗细搜索 → 热力图。
  • 当前真实基线：最大孔径 81.66 mm，最小间距 17.38 mm，混叠起点 9.87 kHz。
  • 延续工程风格：坐标驱动 + LUT 驱动 + Pair set + coarse-to-fine。

坐标定义更新：收音孔坐标 → 封装中心坐标

默认封装定义：根据你给的封装图，默认认为收音孔中心在封装中心的局部坐标 (+0.68 mm, 0.00 mm) 处；0° 时收音孔位于封装中心右侧，角度按逆时针为正。

换算公式：package_center = acoustic_port - R(theta) · [offset_x, offset_y]

  • 性能评估、孔径、混叠起点等仍按收音孔坐标计算。
  • EDA 下板、丝印定位、封装放置改按封装中心坐标。
  • 如果后续封装原点定义有变化，只需改偏移或角度，不用重做阵列设计。
提示：主表里的每个 mic 角度都可以单独改，表格和图会同步刷新。

推荐主方案

主方案：工业化三尺度主方案：Inner8 + Transition8 + Outer16

设计逻辑：把阵列拆成高频短基线层、宽频桥接层和大孔径成像层，同时满足 192k 模式下 4 片 PCMD3180 都参与、每片只开 4 个核心 mic 的带宽现实。

优势：110 mm 级有效孔径 + 7.64 mm 最小间距，兼顾宽频、旁瓣控制和 192k 近场高频精扫。

代价：50~80 kHz 仍主要是近场热点确认，20~50 m 只能承诺强异常检测，不承诺细致热图。

布线建议：U1/U2 共用 TDM_A_BCLK / FSYNC / SDOUT，U3/U4 共用 TDM_B_BCLK / FSYNC / SDOUT。每片按 4 对 PDM 线布线，每对由一个 PDMDINx_GPIx 和一个 PDMCLKx_GPOx 组成，两只 mic 通过 PDM 的 L/R 选边共享这对线。

嵌入式实现建议（面向 STM32N6）

  • 32@48k：4 片全开，双 TDM16，单总线 BCLK 与现有 16@48k 同量级，适合作为默认实时模式。
  • 16@192k：4 片都参与，但每片只开 4 个核心 mic；把每条总线压成 TDM8 后，单总线 BCLK 约 24.576 MHz。
  • 应预计算：pair_idx、pair_dx/dy、coarse TDOA LUT、频带权重、增益 / 相位 / 分数延迟标定表。
  • 不建议预存全 steering 立方体；fine search 继续在线算，保留 coarse-to-fine 的嵌入式风格。
  • 192k 模式更适合触发式、ROI 式、低帧率高质量运行，而不是默认常开。

主要限制因素阵元间距、MEMS 带宽、空气衰减、跨芯片相位误差、外壳散射和假峰。
改善手段切到 Inner8 / Core16、裁掉长基线、频带门控、做宽带标定和前壳声学设计。

5.4 低频能力评估

项目结论
低频现实0.8~2 kHz 主要是粗定位和热点增强，2~4 kHz 才逐渐进入可用成像频段。
值得投入的增强多帧融合、超指向后滤波、IMU 微运动合成孔径都值得做。
不要硬承诺低频高清热图、百米级低频高分辨成像。

5.5 结论必须明确

层级结论
可以承诺0.3~8 m 的工业级检测/定位/成像主能力，0.3~20 m 的强异常检测能力。
可以研究但不应轻承诺20~40 kHz 高频精扫、40~80 kHz 近场热点确认、20~50 m 强异常检测。
物理上基本不现实在 100 mm 级 32 路手持阵列上承诺 50~80 kHz 远距离高质量热图。

风险点与工程注意事项

  • 192k 模式的第一瓶颈是前端时钟和跨芯片一致性，不是 MCU 算力。
  • 跨芯片标定必须流程化，至少覆盖增益、整采样延迟、分数延迟和宽带相位斜率。
  • 高频能力高度依赖前壳开孔、倒角、吸声、支撑柱和相机周边散射控制。
  • 如果后续麦克风封装方向为了布线要做 90° / 180° 调整，可以直接用本页动态表先算封装中心坐标再落板。

最终建议：哪些值得冲，哪些不要硬冲

值得冲

  • 32@48k 主模式下的工业级高质量热图。
  • 16@192k 的近场高频精扫和热点确认。
  • 模式化 Pair set、频带门控、多帧融合和 IMU 微运动补偿。

不要硬冲

  • 50~80 kHz 的远距离高质量全场热图。
  • 100 mm 手持阵列上的百米级低频高分辨成像。
  • 把 MUSIC / MVDR 包装成全流程主算法。

给硬件团队看的简版说明

  • 32@48k：4 片 PCMD3180 全开，每片 8 mic，两条同步 TDM16。
  • 16@192k：4 片也都工作，但每片只开 4 个核心 mic，建议双总线 TDM8。
  • 每片按 4 对 PDM 立体声线来布：DAT1/CLK1，DAT2/CLK2，DAT3/CLK3，DAT4/CLK4。
  • 文档里的性能评估按收音孔坐标算，EDA 放置按封装中心坐标下板。

给算法团队看的简版说明

  • 主流程仍是 SRP-PHAT，但 pair set 必须模式化，不能默认 32 路全对穷举。
  • 32@48k 是主展示模式；16@192k 是高频近场高质量模式，不是默认主画面。
  • 40~80 kHz 只作为近场热点确认，不要讲成远距离全场高质量成像。
  • MVDR/MUSIC 更适合 ROI 精修，不适合替代主流程。
