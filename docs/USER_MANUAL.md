# NECCS 声学相机 — 用户手册

> 版本：2.0 | 更新日期：2026-04-09

---

## 1. 产品简介

NECCS 声学相机是一款基于 STM32H743 (Cortex-M7, 480 MHz) 的 **16 阵元实时声源定位系统**。

系统通过 16 路 PDM MEMS 麦克风阵列采集声音信号，利用 **SRP-PHAT** 算法在二维空间内实时定位声源方向，并将定位结果以热力图形式叠加在 OV2640 摄像头画面上，直观呈现声源位置。

**核心功能：**

- 实时声源方位估计（方位角 + 俯仰角）
- 声学热力图可视化
- 热力图与摄像头画面融合叠加显示
- 动态频段过滤（带通滤波）
- 瞬态捕捉模式（声音突变冻结）
- 激光瞄准器与黑夜模式
- 声级计（A/C/Z加权 dB 显示）
- 异常声检测与追踪
- 定向录音（DAS 波束成形）
- SD 卡截图与录音
- 多场景预设一键切换
- 触摸屏工业级 UI 参数控制
- 串口在线参数调节

## 2. 技术规格

| 项目 | 参数 |
|------|------|
| 麦克风 | 16 通道 PDM MEMS |
| 采样率 | 48 kHz |
| 帧长 | 256 点 |
| 定位算法 | SRP-PHAT（粗搜 + 细搜两级） |
| 粗搜索网格 | 9×9，覆盖 ±60° |
| 细搜索网格 | 4×4，Top-3 峰值精搜，半跨度 ±10° |
| 定位精度 | 约 15°（粗搜）/ 约 5°（精搜） |
| 显示屏 | 800×480 RGB LCD (LTDC) |
| 摄像头 | OV2640 (320×240 预览) |
| 处理器 | STM32H743 @ 480 MHz |
| 操作系统 | FreeRTOS |
| 显示帧率 | 默认 20 FPS（可调 5–30 FPS） |
| 调试接口 | USART1, 921600 baud |

## 3. 硬件连接

### 3.1 供电

系统通过 ST-Link 或外部 5V 电源供电。确保供电稳定，建议使用 USB 供电口或稳压电源。

### 3.2 调试串口

| 引脚 | 说明 |
|------|------|
| USART1 TX | 调试信息输出 |
| USART1 RX | CLI 命令接收 |
| 波特率 | **921600** |
| 数据位 | 8 位，无校验，1 停止位 |

使用任意串口工具（PuTTY、SecureCRT、MobaXterm 等）连接，输入命令后回车生效。

### 3.3 ST-Link

通过 SWD 接口连接 ST-Link 调试器，用于固件烧录和调试。连接 SWDIO、SWCLK、GND 三根线即可。

## 4. 首次使用

### 4.1 上电启动流程

系统上电后会依次执行以下启动阶段：

| 阶段 | 说明 |
|------|------|
| IDLE | 系统初始化前空闲状态 |
| SOFT_I2C | 软件 I2C 总线初始化 |
| APP_STREAM | 音频流初始化 |
| APP_TASK | FreeRTOS 应用任务创建 |
| SAI_DMA | SAI + DMA 音频采集通道启动 |
| CLOCK_WAIT | 等待外部时钟锁定 |
| PCMD0 / PCMD1 | PDM 麦克风 0/1 配置 |
| CAMERA_INIT | OV2640 摄像头初始化 |
| CAMERA_START | 摄像头开始采集 |
| DONE | 启动完成，进入正常工作 |

正常情况下从上电到 DONE 仅需数秒。若某一阶段卡住，串口会输出当前停留的阶段名称，可据此排查。

### 4.2 LED 状态指示

- **LED 常亮**：系统正常运行
- **LED 闪烁**：系统正在初始化或出现异常

### 4.3 正常工作状态

启动完成后：
- LCD 显示摄像头画面叠加声学热力图
- 右侧面板显示定位角度、帧率、模式等状态信息
- 串口打印 `UI CLI ready @921600 baud, type 'cfg help'`

## 5. 显示界面说明

### 5.1 屏幕导航

系统采用 LVGL 多屏幕框架，包含 6 个屏幕：

| 屏幕 | 进入方式 | 功能 |
|------|----------|------|
| **Home** | 上电启动 | 系统信息展示，点击"START"进入主视图 |
| **Main** | Home 点击 START | 热力图 + 频谱面板 + 状态栏 + 工具栏 |
| **Settings** | Main 点击⚙ | 参数调节（频段、gamma、噪声门、插值等） |
| **Capture** | Main 点击📷 | 截图 + 录音 + 波束控制 + SD 状态 |
| **Diagnostics** | Main 点击📊 | 性能图表 + 系统信息 |
| **Guide** | Settings 点击? | 使用说明文字 |

### 5.2 Main 主视图

| 区域 | 尺寸 | 内容 |
|------|------|------|
| 主视图 | 640×480 | 摄像头画面 + 热力图叠加 |
| 右侧面板 | 160×480 | 频谱图 + 角度/能量/dB 读数 |
| 状态栏 | 顶部 | FPS、模式、SAI 状态、触发/激光指示 |
| 工具栏 | 底部 | 模式信息 + 功能按钮 |

### 5.3 Settings 设置屏

| 控件 | 功能 |
|------|------|
| 频段滑块 (Lo/Hi) | 带通滤波频率范围 (Hz) |
| Gamma 滑块 | 热力图亮度曲线 (0.5-3.0) |
| 噪声门滑块 | 噪声抑制强度 (0-100%) |
| 插值开关 | 最近邻/双线性切换 |
| 精搜开关 | 精细扫描使能 |
| 激光开关 | 外接激光器使能 |
| 夜间模式开关 | 黑夜辅助显示 |
| 预设按钮 | 通用/气体泄漏/轴承/局放一键切换 |
| 噪声校准 | 执行噪底自适应校准 |

### 5.4 Capture 数据捕获屏

**左卡片 — 截图：**
- 截图计数显示
- 截图状态（Ready / Saving / Saved!）
- 触发按钮：点击一次截取当前热力图+摄像头画面为 BMP 文件

**右卡片 — 录音：**
- 模式下拉：MONO（定向单通道）/ RAW16（原始 16 通道）
- Start/Stop 切换按钮（录音中红色脉冲动画）
- 实时录音时长显示 (HH:MM:SS)
- 数据量/帧数/丢帧统计
- 波束控向控制：
  - 使能开关：开启/关闭 DAS 波束成形
  - 模式下拉：Auto（自动追踪声源）/ Manual / Trigger
  - 实时方向显示（θ, φ）

**SD 状态栏（底部）：**
- 挂载状态（Mounted / Not Mounted / Error）
- 使用量进度条（>70% 黄色，>90% 红色）
- 可用空间 / 总容量

### 5.2 声学热力图

热力图以半透明色块叠加在摄像头画面上，用颜色表示声源能量分布：

- **蓝色** → 低能量（安静区域）
- **绿色 → 黄色** → 中等能量
- **红色** → 高能量（声源方向）

图中有 **十字准星** 标记当前检测到的声源峰值方向。

### 5.3 显示模式

系统内置三种显示预设，可通过串口切换：

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| **FAST** | 最高刷新率，无平滑，最近邻插值 | 追求响应速度 |
| **BALANCED** | 平衡画质与速度 | 日常使用 |
| **CLEAN** | 双线性插值，多次平滑，精细融合 | 追求画质和定位清晰度 |

默认上电为 **FAST** 模式。

### 5.4 触摸操作

系统支持触摸屏（需硬件支持）。触摸功能默认开启，初始化失败会自动重试。

## 6. 串口调试

### 6.1 连接方式

1. 用 USB 转串口线连接 USART1
2. 打开串口工具，设置 **921600, 8N1**
3. 输入命令后按回车执行

### 6.2 常用命令速查

#### 帮助与状态

| 命令 | 说明 |
|------|------|
| `help` | 显示顶层帮助 |
| `cfg help` | 显示所有配置命令帮助 |
| `cfg status` | 查看当前参数和 DMA2D 状态 |

#### 模式切换

| 命令 | 说明 |
|------|------|
| `cfg mode fast` | 切换到 FAST 模式 |
| `cfg mode balanced` | 切换到 BALANCED 模式 |
| `cfg mode bal` | `balanced` 的简写 |
| `cfg mode clean` | 切换到 CLEAN 模式 |

#### 画质调节

| 命令 | 范围 | 说明 |
|------|------|------|
| `cfg contrast <值>` | -80 ~ -6 | 动态范围底噪（dB），值越负，动态范围越大 |
| `cfg gamma <值>` | 0.5 ~ 2.5 | 热力图 gamma，>1 增强对比度 |
| `cfg noise <值>` | 0 ~ 0.6 | 噪声门限比例，值越大过滤噪声越多 |
| `cfg adapt <值>` | 0 ~ 6 | 背景噪声自适应增益 |
| `cfg smooth <值>` | 0 ~ 3 | 空间平滑迭代次数 |
| `cfg fine <值>` | 0 ~ 3 | 细搜索融合增益 |
| `cfg bilinear <0\|1>` | 0 或 1 | 0=最近邻插值，1=双线性插值 |
| `cfg interp nearest\|bilinear` | — | 同上，另一种写法 |

#### 刷新与显示

| 命令 | 范围 | 说明 |
|------|------|------|
| `cfg textdiv <值>` | 1 ~ 20 | 文本刷新分频，越大帧率压力越小 |
| `cfg blit <值>` | 1 ~ 8 | 块渲染行数 |

#### 摄像头控制

| 命令 | 说明 |
|------|------|
| `cfg cam retry` | 手动重试摄像头初始化 |
| `cfg camfreeze on\|off` | 冻结/恢复摄像头画面 |
| `cfg camview overlay\|camera\|heat\|freeze` | 切换显示视图 |

### 6.3 参数调节建议

**背景噪声偏多时：**
1. 提高噪声门限：`cfg noise 0.10` ~ `0.18`
2. 提高自适应增益：`cfg adapt 2.0` ~ `3.5`
3. 增加平滑：`cfg smooth 1` 或 `cfg smooth 2`

**对比度不足时：**
1. 调低底噪阈值：`cfg contrast -40` ~ `-55`
2. 配合提高 gamma：`cfg gamma 1.1` ~ `1.4`

**追求最高帧率：**
- `cfg mode fast`

## 7. SD 卡使用

### 7.1 SD 卡要求

| 项目 | 推荐 |
|------|------|
| 格式 | FAT32 |
| 容量 | 4 GB ~ 32 GB |
| 速度等级 | Class 10 或 UHS-I |
| 接口 | MicroSD |

### 7.2 截图操作

1. 进入 **Capture 屏幕**（从 Main 屏幕点击📷按钮）
2. 点击 **Take Screenshot** 按钮
3. 等待状态从"Saving..."变为"Saved!"
4. 截图保存为 `0:/NECCS/CAPTURE/IMG_000001.bmp`（自动编号递增）
5. 分辨率：800×480，24-bit BMP，约 1.1 MB/张

### 7.3 录音操作

1. 进入 **Capture 屏幕**
2. 选择录音模式：
   - **MONO (Beam)**：定向单通道录音（需开启波束使能），48 kHz/16-bit/1ch
   - **RAW16 (16ch)**：原始全通道录音，48 kHz/16-bit/16ch
3. 点击 **START** 按钮开始录音
4. 录音中按钮变红并脉冲闪烁，显示实时时长和数据量
5. 点击 **STOP** 停止录音
6. WAV 文件保存为 `0:/NECCS/RECORD/REC_000001.wav`（自动编号递增）

### 7.4 定向录音（波束成形）

1. 在 Capture 屏幕右卡片底部，打开 **Beamforming** 开关
2. 选择追踪模式：
   - **Auto**：自动跟踪 SRP-PHAT 检测到的主声源方向
   - **Manual**：通过 UI/CLI 手动设定方向
   - **Trigger**：触发时锁定当前方向
3. 选择 **MONO (Beam)** 模式录音，即可录制定向增强音频

### 7.5 定时注意事项

- MONO 模式数据率约 96 KB/s，32GB 卡可连续录音约 92 小时
- RAW16 模式数据率约 1536 KB/s，32GB 卡可连续录音约 5.7 小时
- 录音期间避免拔出 SD 卡，否则录音文件可能损坏
- SD 空间不足（<10 MB）时系统自动停止录音

## 8. 故障排除

### 8.1 屏幕不亮

1. 检查供电是否正常（电压 5V / 3.3V 稳定）
2. 检查 LCD 排线连接是否牢固
3. 串口观察启动阶段是否卡在 `CAMERA_INIT` 之前的某个阶段
4. 显示初始化失败后系统会自动每 1 秒重试一次

### 8.2 声音定位不准确

1. 确认麦克风阵列各通道焊接正常、无虚焊
2. 确认声源距离不宜过远，建议 0.5–3 米范围
3. 避免强反射环境（如空旷金属房间）
4. 尝试切换到 CLEAN 模式增大精度：`cfg mode clean`
5. 检查是否有持续强噪声干扰，可适当提高 `cfg noise` 值

### 8.3 系统无响应

1. 检查供电和 ST-Link 连接
2. 通过串口查看是否有输出，判断系统是否仍在运行
3. 按复位键重启系统
4. 若串口持续无输出，尝试重新烧录固件

### 8.4 DMA2D 超时告警

`cfg status` 输出中若 `dma2d timeout` 持续增长，表明 DMA2D 硬件传输异常：

1. 检查是否多个外设同时大量使用 AXI 总线
2. 尝试降低帧率：切换到 FAST 模式减少 DMA2D 负载
3. 若 `dma2d fallback` 增长，系统已自动回退至 CPU 软渲染，功能不受影响但帧率会下降

### 8.5 摄像头画面异常

1. 检查 OV2640 模块连接（DCMI 排线、I2C 地址线）
2. 串口输入 `cfg cam retry` 手动重试初始化
3. 若画面撕裂，尝试 `cfg camfreeze on` 冻结画面定位问题
