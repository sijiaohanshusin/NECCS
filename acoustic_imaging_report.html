问题A: 算法路线选型分析

本节对三种主流声源定位算法SRP-PHAT、MUSIC 和频域 DAS 在16阵元+STM32H7 嵌入式平台上的适用性进行深度对比。

三大算法核心原理概述

① 频域 DAS (Delay-and-Sum Beamforming): 最经典的波束形成方法。对每个候选方向,将各通道信号按预计算的时延进行对齐后求和,输出功率最大的方向即为声源方向。数学表达:

$$P_{DAS}(q)=\left|\sum_{m=1}^{M}w_{m}\cdot X_{m}(f)\cdot e^{j2\pi f\tau_{m}(q)}\right|^{2}$$
式(1): DAS 波束形成输出功率

② MUSIC (Multiple Signal Classification): 基于协方差矩阵特征分解的超分辨算法。将信号空间分解为信号子空间和噪声子空间,通过搜索与噪声子空间正交的指向矢量来定位声源:

$$P_{MUSIC}(q)=\frac{1}{a^{H}(q)E_{n}E_{n}^{H}a(q)}$$
式(2): MUSIC空间谱，$E_n$ 为噪声子空间

③ SRP-PHAT (Steered Response Power Phase Transform): 将GCC-PHAT互相关结果在空间网格上进行累积。PHAT 加权通过谱白化消除幅度影响,仅保留相位信息,使得在混响环境下仍能保持尖锐的相关峰:

$$P_{SRP}(q)=\sum_{k=1}^{M}\sum_{l=k+1}^{M}\sum_{f}Re\left[\frac{X_{k}(f)X_{l}^{*}(f)}{|X_{k}(f)X_{l}^{*}(f)|}\cdot e^{j2\pi f\Delta\tau_{kl}(q)}\right]$$
式(3): 频域 SRP-PHAT 功率谱 (核心公式)

MUSIC 在 STM32H7上的不可行性分析

MUSIC 算法的核心瓶颈在于协方差矩阵的特征分解。对于16路麦克风,需要对16×16的复数协方差矩阵执行特征值分解(EVD)。即使使用优化的Jacobi 迭代法:

$$R_{xx}=\frac{1}{L}\sum_{l=1}^{L}X(f_{l})X^{H}(f_{l})=E_{s}\Lambda_{s}E_{s}^{H}+\sigma^{2}E_{n}E_{n}^{H}$$
式(4): 协方差矩阵特征分解
MUSIC 计算步骤 运算量 M=16 实际值 耗时估算 @480MHz
协方差矩阵估计 $O(M^2\cdot F)$ 256x256=32.8K 复数MAC ~0.3 ms
特征值分解(EVD) $O(M^3)$ 迭代 ~50次 Jacobi旋转×4096 ~1.5-2.0 ms
空间谱搜索(每网格点) $O(M^2)$ 矩阵乘 256 × N网格点 ~0.5ms (8×8网格)
总计 ~2.3-2.8 ms

▲ 关键问题: MUSIC的EVD单步就消耗近2ms,且在混响环境下协方差矩阵估计需要更多帧累积(≥10帧)才能稳定,这直接导致成像延迟≥50ms,无法满足30FPS实时要求。此外,MUSIC 需要预知声源数目,在竞赛场景下不实际。

频域 DAS 的局限性

频域 DAS 虽然计算量最小,但其空间分辨率受到阵列孔径的物理限制。对于本阵列(~75mm孔径),在1kHz频率下的3dB 波束宽度约为:

$$\theta_{3dB}\approx\frac{\lambda}{D}=\frac{343/1000}{0.075}\approx4.57\text{ rad}\approx262^{\circ}$$
式(5): 低频波束宽度(1kHz) 分辨率极差

即使在4kHz下,波束宽度仍约65°,这意味着DAS 在中低频段几乎无法区分不同方向的声源。在国赛的室内环境中,混响会进一步模糊 DAS 的成像结果。

SRP-PHAT 的决定性优势

为什么 SRP-PHAT 是最优选择?
  • PHAT 白化: 通过 $1/|X_{k}X_{l}^{*}|$ 归一化,消除频谱幅度的影响,等效地对所有频率分量赋予相同权重。这使得在混响环境下,直达声路径的相位信息被最大化保留。
  • 120对冗余: 16路麦克风产生C(16,2)=120个互相关对,远多于最少所需的2对。大量冗余通过空间累积有效抑制了虚假峰值。
  • 频域直接累积(关键优化): 无需执行120次IFFT。直接在频域用预计算的相位矢量进行旋转累积,大幅降低计算量。
  • 粗细结合搜索: 通过两级网格搜索将空间扫描点从3600+降至~112,使得在H7上实现≥30FPS 完全可行。
  • 无需先验信息: 不需要预知声源数目,不需要长时间的协方差矩阵累积,单帧即可成像。

问题B: SRP-PHAT 高效数学降维

本节详细推导频域 SRP-PHAT的GCC-PHAT计算公式,并提供跳过IFFT的频域直接累积方案与粗细结合搜索策略。

B.1 GCC-PHAT 交叉功率谱公式推导

对于麦克风对(i,j),设其频域信号为 $X_{i}(f_{k})$ 和 $X_{j}(f_{k})$ (由256点RFFT得到, $k=0,1,...,127$), GCC-PHAT 的计算分为以下几步：

① 交叉功率谱 (Cross-Power Spectrum)

$$G_{ij}(f_{k})=X_{i}(f_{k})\cdot X_{j}^{*}(f_{k})$$
式(6): 复数共轭乘法,输出为复数

其中 $X_{j}^{*}(f_{k})$ 为 $X_{j}(f_{k})$ 的复共轭。在CMSIS-DSP中,频域数据以交织格式 $[Re_{0},Im_{0},Re_{1},Im_{1},...]$ 存储。

② PHAT 相位加权 (Phase Transform)

$$\tilde{G}_{ij}(f_{k})=\frac{G_{ij}(f_{k})}{|G_{ij}(f_{k})|+\epsilon}=\frac{X_{i}(f_{k})\cdot X_{j}^{*}(f_{k})}{|X_{i}(f_{k})\cdot X_{j}^{*}(f_{k})|+\epsilon}$$
式(7): PHAT 白化——仅保留相位信息, $\epsilon=10^{-16}$ 防除零

白化后 $|\tilde{G}_{ij}(f_{k})| \approx 1$,即所有频率分量权重相等。这是SRP-PHAT 抗混响的核心机制。

③ 频域 SRP 累积 (跳过IFFT的关键优化)

$$P(q)=\sum_{i=1}^{M}\sum_{j=i+1}^{M}\sum_{k=0}^{K-1}Re\left[\tilde{G}_{ij}(f_{k})\cdot e^{j2\pi f_{k}\cdot\Delta\tau_{ij}(q)}\right]$$
式(8): 频域直接累积SRP功率 无需IFFT
  • $K = 128$ 为有效频点数(RFFT 正频部分)
  • $f_{k}=k\cdot\Delta f=k\times187.5$ Hz 为第k个频率 bin
  • $\Delta\tau_{ij}(q)$ 为候选声源位置q到麦克风对(i,j)的时延差(TDOA)
  • $e^{j2\pi f_{k}\Delta\tau_{ij}(q)}$ 为预计算的相位旋转因子(Steering Phase)
核心优化: 传统方法需要对120对麦克风分别做IFFT (120×256点IFFT=巨大开销)。而式(8)直接在频域用预计算的相位因子旋转后实部累加,将120次IFFT 替换为120×128次复数乘法+实部取出,计算量降低约10倍。

B.2 展开式(8)的实数运算细节

将复数乘法展开为实数运算,令 $\tilde{G}_{ij}(f_{k})=a+jb$，预计算相位 $e^{j\phi}=\cos\phi+j\sin\phi$

$$Re[(a+jb)(\cos\phi+j\sin\phi)]=a\cos\phi-b\sin\phi$$
式(9): 每个(对,频点,网格点)仅需2次乘法+1次减法

因此,对于单个网格点的SRP功率累积:

$$P(q)=\sum_{(i,j)\in\mathcal{P}}\sum_{k=0}^{127}[a_{ij,k}\cos(\phi_{ij,k}(q))-b_{ij,k}\sin(\phi_{ij,k}(q))]$$
式(10): 完全展开的实数运算形式，$\mathcal{P}$为120个麦克风对集合

B.3 粗细结合搜索策略 (Coarse-to-Fine)

朴素 SRP-PHAT在60×60=3600个网格点上搜索,对H7来说计算量过大。粗细结合策略将搜索分为两级:

  • 第一级：粗搜索。 8×8 = 64个网格点。提取 Top-3 峰值区域。
  • 第二级：细搜索。 在Top-3峰值周围，每块4×4个网格点进行细化。

搜索空间设计

假设声源在阵列前方0.3m~3.0m范围,扫描平面的角度范围为 $\pm60^{\circ}$(方位角和俯仰角),采用球坐标$(\theta,\varphi)$参数化:

  • 粗搜索: $\theta\in[-60^{\circ},60^{\circ}]$, 步长15° ; $\varphi\in[-60^{\circ},60^{\circ}]$ 步长15°。共 $9\times9=81$ 点(或简化为8×8=64点)。
  • 细搜索: 在Top-3粗峰值周围 $\pm7.5^{\circ}$ 范围内,步长3.75°。每个峰值区域4×4=16点,共48点。
  • 总计: $64+48=112$ 个网格点(相比 $60\times60=3600$ 减少97%)。

伪代码实现

// 粗细结合 SRP-PHAT
// 输入: GCC_PHAT [120][128] - 120对的白化交叉功率谱(复数)
// 输入: Steer_cos/sin [64][120][128] - 粗网格预计算相位
// 输入: FineCos/Sin [48][120][128] - 细网格预计算相位

float SRP_Coarse[64];
// ============ 粗搜索 (8×8=64点) ============
for (n = 0; n < 64; n++) {
    SRP_Coarse[n] = 0.0f;
    for (p = 0; p < 120; p++) {        // 遍历 120对
        float acc = 0.0f;
        for (k = 0; k < 128; k++) {    // 遍历 128 点
            float a = GCC_re[p][k];
            float b = GCC_im[p][k];
            float c = Steer_cos[n][p][k]; 
            float s = Steer_sin[n][p][k]; 
            acc += a*c - b*s;          // Re[G * exp(j_phi)]
        }
        SRP_Coarse[n] += acc;
    }
}
top3_idx = find_top3(SRP_Coarse, 64); // 提取 Top-3 峰值

// ============ 细搜索 (3*4*4=48点) ============
float SRP_Fine[48];
for (n = 0; n < 48; n++) {
    SRP_Fine[n] = 0.0f;
    for (p = 0; p < 120; p++) {
        float acc = 0.0f;
        for (k = 0; k < 128; k++) {
            acc += GCC_re[p][k] * FineCos[n][p][k] 
                 - GCC_im[p][k] * FineSin[n][p][k];
        }
        SRP_Fine[n] += acc;
    }
}
best_fine_idx = argmax(SRP_Fine, 48);
best_pos = FineGrid[best_fine_idx]; // 输出最佳声源方向

问题C: 空间流形矩阵预计算

利用麦克风坐标固定的特性,预先计算所有网格点的TDOA延迟表和指向相位矢量,固化到 Flash/SDRAM中,运行时零延迟查表。

C.1 TDOA 延迟公式推导

设麦克风的位置为 $r_{i}=(x_{i},y_{i},0)$(阵列在 $z=0$ 平面),候选声源位置为 $q=(q_{x},q_{y},q_{z})$。声源到麦克风的传播距离为:

$$d_{i}(q)=||q-r_{i}||=\sqrt{(q_{x}-x_{i})^{2}+(q_{y}-y_{i})^{2}+q_{z}^{2}}$$
式(11): 声源到麦克风的欧氏距离

麦克风对(i,j)的TDOA(到达时间差)为:

$$\Delta\tau_{ij}(q)=\frac{d_{i}(q)-d_{j}(q)}{c}=\frac{||q-r_{i}||-||q-r_{j}||}{c}$$
式(12): TDOA核心公式, c=343 m/s

远场近似 (Far-field Approximation)

当声源距离 $\gg$ 阵列孔径时(如 $d>0.5m$ vs 孔径75mm),可采用平面波近似。设声源方向为单位向量 $\hat{u}=(\sin\theta\cos\varphi, \sin\theta\sin\varphi, \cos\theta)$, 则:

$$\Delta\tau_{ij}(\hat{u})\approx\frac{(r_{i}-r_{j})\cdot\hat{u}}{c}=\frac{(x_{i}-x_{j})\sin\theta\cos\varphi+(y_{i}-y_{j})\sin\theta\sin\varphi}{c}$$
式(13): 远场平面波TDOA近似 仅依赖方向角,计算更简单
建议: 国赛场景声源距离通常 0.5m-3m,远场近似的误差在±0.1 μs以内,推荐使用远场模型以简化预计算。若需近场精度,使用式(12)的球面波模型。

C.2 指向相位矢量 (Steering Phase Vector) 预计算

对于频域 SRP-PHAT的式(8),每个(网格点n,麦克风对p,频点k)需要的相位旋转因子为:

$$\phi_{p,k}^{(n)}=2\pi\cdot f_{k}\cdot\Delta\tau_{p}^{(n)}=2\pi\cdot(k\cdot187.5)\cdot\Delta\tau_{p}^{(n)}$$
式(14): 相位角 $f_{k}=k\times\Delta f$, $\Delta f=48000/256=187.5$ Hz

预计算并存储其cos 和 sin值:

$$SteerCos[n][p][k]=\cos(\phi_{p,k}^{(n)}), \quad SteerSin[n][p][k]=\sin(\phi_{p,k}^{(n)})$$
式(15): 预计算cos/sin 查找表

C.4 内存优化: TDOA 索引法(推荐方案)

直接存储 cos/sin 表需要13.1MB,不可接受。核心优化思路:只存储TDOA延迟值,运行时实时计算 cos/sin。

$$TDOA\_LUT[n][p]=\Delta\tau_{p}^{(n)} \quad (\text{float32, 单位:秒})$$
式(16): 仅存储 TDOA值,维度[网格点数][麦克风对数]
方案 维度 存储大小 存储位置 运行时开销
方案A:全量cos/sin [112] [120] [128]×2 13.1 MB SDRAM (慢) 零(纯查表)
方案B:TDOA 索引法 √ [112] [120] 52.5 KB AXI SRAM 实时计算 cos/sin
方案C:量化int16 [112] [120] [128]×2 6.6 MB SDRAM 反量化

推荐方案B: TDOA索引法仅需52.5KB,完全放入AXI SRAM(零等待访问)。运行时在内循环中对每个频点k,计算 $\phi = 2\pi k\Delta f \cdot TDOA[n][p]$，然后用快速 sin/cos 查表或CORDIC 求值。Cortex-M7的FPU执行 sinf()/cosf() 约需20~30周期,128频点的额外开销约 $120\times128\times30 \approx 460K$ 周期 $\approx 1ms$, 总耗时仍在5ms以内。

    [65.00, 50.00], [36.45, 62.41], [51.85, 28.87], [64.43, 68.82],
    [24.42, 45.47], [73.68, 34.94], [42.21, 78.97], [35.35, 21.76],
    [81.51, 61.51], [17.48, 63.42], [65.57, 16.72], [61.44, 86.49],
    [15.66, 30.18], [90.12, 41.18], [25.66, 84.71], [44.38, 6.63]
]) / 1000.0  # 转换为米

c = 343.0  # 声速
pairs = list(combinations(range(16), 2)) # 120 对

# 构建粗搜索网格(8x8)
theta_coarse = np.linspace(-60, 60, 8) # 方位角(度)
phi_coarse = np.linspace(-60, 60, 8)   # 俯仰角(度)

def compute_tdoa_farfield(theta_deg, phi_deg, pair):
    # 远场TDOA = (r_i - r_j) · u_hat / c
    th = np.radians(theta_deg)
    ph = np.radians(phi_deg)
    u_hat = np.array([np.sin(th)*np.cos(ph), np.sin(th)*np.sin(ph)])
    i, j = pair
    dr = mic_pos[i] - mic_pos[j]
    return np.dot(dr, u_hat) / c

# 计算粗网格 TDOA LUT
N_coarse = len(theta_coarse) * len(phi_coarse) # 64
tdoa_lut = np.zeros((N_coarse, 120), dtype=np.float32)

grid_idx = 0
for th in theta_coarse:
    for ph in phi_coarse:
        for p, pair in enumerate(pairs):
            tdoa_lut[grid_idx, p] = compute_tdoa_farfield(th, ph, pair)
        grid_idx += 1

# 写入C头文件
with open("tdoa_lut_coarse.h", "w") as f:
    f.write("// 自动生成粗搜索 TDOA LUT [64][120]\n")
    f.write("const float TDOA_Coarse[64][120] = {\n")
    for n in range(N_coarse):
        vals = ", ".join(f"{v:.9e}f" for v in tdoa_lut[n])
        f.write(f"    {{{vals}}},\n")
    f.write("};\n")

C.6 Flash 固化策略

  • 粗网格 TDOA LUT: $64\times120\times4B = 30\text{ KB} \rightarrow$ 存放 STM32H7 内部 Flash (2MB容量)。
  • 细网格 TDOA LUT: 需要在粗搜索后动态确定位置,有两种策略:
    • 策略A(预计算全量): 预计算所有可能的细网格区域,存入Flash。对64个粗格各16个细点，即 $1024\times120\times4B = 480\text{ KB}$，可存入Flash。
    • 策略B(运行时计算): 仅存粗网格TDOA,细网格TDOA 在确定 Top-3后实时计算 $48\times120=5760$ 次远场TDOA 计算(式13),每次约10周期 $\rightarrow$ ~0.12ms,可接受。
推荐: 采用策略A (Flash全量预计算)。480KB对2MB Flash 毫无压力,且运行时完全零计算开销。将TDOA LUT 通过 __attribute__((section(".flash_data"))) 放入Flash的指定段。

问题D: CMSIS-DSP的巧妙运用

本节说明如何将GCC-PHAT与SRP 累积的每一步映射到CMSIS-DSP函数,最大化利用Cortex-M7的单精度FPU 流水线。

D.1 关键 CMSIS-DSP 函数映射

CMSIS-DSP 函数 算法步骤 用途说明
arm_cmplx_mult_cmplx_f32 交叉功率谱(式6) $G_{ij}(k)=X_{i}(k)\cdot X_{j}^{*}(k)$ 需先对 $X_j$ 取共轭
arm_cmplx_mag_f32 PHAT归一化分母 计算 $|G_{ij}(k)|=\sqrt{Re^2+Im^2}$, 用于白化除法。
arm_cmplx_conj_f32 复共轭 对 $X_j$ 取共轭: $Im \rightarrow -Im$
arm_dot_prod_f32 SRP 频域累积 将式(10)分解为两个点积之差: $\sum a_{k}c_{k} - \sum b_{k}s_{k}$
arm_rfft_fast_f32 实数FFT(已完成) 256点 RFFT,输出交织格式 [Re, Im, Re, Im...]。
arm_max_f32 峰值检测 在SRP 数组中找最大值及其索引

D.2 GCC-PHAT 核心循环C代码实现

// GCC-PHAT 计算: 120对麦克风的白化交叉功率谱
// 输入: Mic_Freq_Buffer[16][256] - 交织复数[Re0, Im0, Re1, Im1...]
// 输出: GCC_Re/Im[120][128] - 白化后的交叉功率谱(实/虚部)

#include "arm_math.h"

#define N_FFT    256   // FFT 长度
#define N_BINS   128   // 正频部分 (N_FFT/2)
#define NUM_MICS 16
#define N_PAIRS  120
#define EPSILON  1e-10f

// 预计算的麦克风对索引 (Flash中)
static const uint8_t pair_i[N_PAIRS];
static const uint8_t pair_j[N_PAIRS];

// 工作缓冲区 (DTCM 或 AXI SRAM)
float32_t conj_buf[N_FFT];
float32_t cross_buf[N_FFT];
float32_t mag_buf[N_BINS];

// 输出
float32_t GCC_Re[N_PAIRS][N_BINS]; // PHAT 白化后实部
float32_t GCC_Im[N_PAIRS][N_BINS]; // PHAT 白化后虚部

void compute_gcc_phat_all(float32_t Mic_Freq[][N_FFT]) {
    for (uint32_t p = 0; p < N_PAIRS; p++) {
        uint8_t mi = pair_i[p], mj = pair_j[p];

        // Step 1: 对 X_j 取共轭
        arm_cmplx_conj_f32(Mic_Freq[mj], conj_buf, N_BINS);

        // Step 2: X_i * X_j^*
        arm_cmplx_mult_cmplx_f32(Mic_Freq[mi], conj_buf, cross_buf, N_BINS);

        // Step 3: 计算幅度 |G_ij|
        arm_cmplx_mag_f32(cross_buf, mag_buf, N_BINS);

        // Step 4: PHAT 白化除法
        for (uint32_t k = 0; k < N_BINS; k++) {
            float32_t inv_mag = 1.0f / (mag_buf[k] + EPSILON);
            GCC_Re[p][k] = cross_buf[2*k] * inv_mag;
            GCC_Im[p][k] = cross_buf[2*k+1] * inv_mag;
        }
    }
}

D.3 SRP 频域累积的向量化技巧

式(10)的核心内循环 $\sum_{k}(a_{k}c_{k}-b_{k}s_{k})$ 可分解为两次 arm_dot_prod_f32:

// 单个网格点 SRP 累积
float32_t compute_srp_single_grid(
    uint32_t grid_idx,
    float32_t cos_lut[][N_BINS],  // [N_PAIRS][N_BINS] 运行时计算或查表
    float32_t sin_lut[][N_BINS]) 
{
    float32_t srp_power = 0.0f;

    for (uint32_t p = 0; p < N_PAIRS; p++) {
        float32_t dot_ac, dot_bs;

        // 利用 FPU流水线的128维 MAC
        arm_dot_prod_f32(GCC_Re[p], cos_lut[p], N_BINS, &dot_ac);
        arm_dot_prod_f32(GCC_Im[p], sin_lut[p], N_BINS, &dot_bs);

        srp_power += (dot_ac - dot_bs); // Re[G * exp(j_phi)]
    }

    return srp_power;
}
FPU 流水线优化: arm_dot_prod_f32 内部展开为4路并行MAC(乘累加),每次循环处理4个float32。128个频点仅需32次循环迭代,充分利用Cortex-M7的FPU单周期乘法和双发射流水线。相比逐元素的标量循环,吞吐量提升约3~4倍。

系统流水线与性能总结

端到端处理流程

  • DMA 双缓冲接收 (与计算并行)
    16路 I2S/SAI DMA交织传输 → Ping-Pong缓冲区,非缓存区域(MPU配置)
    ~0 ms (与上一帧计算重叠)
  • 时域预处理 (已完成)
    解交织 → 加汉宁窗 → 256点 arm_rfft_fast_f32 × 16路 → Mic_Freq_Buffer[16][256]
    ~0.4 ms (16 x 256点 RFFT)
  • GCC-PHAT 计算 (120对)
    共轭 → 复数乘法 → 幅度计算 → PHAT 白化 → GCC_Re/Im[120][128]
    ~0.8 ms
  • 粗搜索 (8×8=64点)
    TDOA LUT查表 → 实时cos/sin → arm_dot_prod_f32 向量累积 → Top-3峰值提取

    在Top-3 粗格周围细化 → 精确声源方向(θ,φ)
    ~0.9 ms
  • 后处理 & 输出
    声源坐标映射 → 热力图更新 → 串口/LCD 输出
    ~0.2 ms
