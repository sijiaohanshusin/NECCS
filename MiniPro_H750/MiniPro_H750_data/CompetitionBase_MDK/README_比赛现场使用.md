# MiniPro H750 综测基础工程

本工程以正点原子 `MiniPro STM32H750` 官方 TFTLCD（MCU 屏）HAL 例程为基础，面向嵌赛国赛 ST 赛道综测整理。当前工程已经在实物 `STM32H750VBT6 + ATK-MD0430 4.3 寸 TFTLCD + 正点原子 DAP DEBUGGER` 上完成编译、下载和 CPU 运行检查。

## 1. 一键使用

工程文件：`Projects/MDK-ARM/atk_h750.uvprojx`

- 双击 `Tools/Build.bat`：重新编译。
- 双击 `Tools/Flash_DAP.bat`：用 CMSIS-DAP 下载并校验。
- 双击 `Tools/Build_And_Flash_DAP.bat`：先编译再下载。
- 串口监视：PowerShell 运行 `Tools/Serial_Monitor.ps1 -Port COM9 -Baud 115200`。

本机 Keil 路径是 `D:\Keil5\UV4\UV4.exe`。换电脑后若路径不同，只改三个批处理文件开头的 `KEIL_UV4`。

## 3. P5 转接板建议

P5 是 `2×12` 排针：照片中靠开发板外缘的一列为奇数脚，靠 MCU 的一列为偶数脚。为了让 LED、外接按键和 GND 全部位于同一列，LED/按键洞洞板只使用外侧奇数列最上方连续七个位置，即 `P5-1、3、5、7、9、11、13`，焊接一条 `1×7、2.54 mm` 单排排母即可。洞洞板应向开发板外侧伸展，不要压住内侧偶数列。

| 外侧单列位置（从上到下） | P5 引脚 | MCU 网络 | 转接板用途 |
|---:|---:|---|---|
| 1 | 1 | GND | 公共地 |
| 2 | 3 | PB14 | LED1，经 330 Ω 限流电阻 |
| 3 | 5 | PB15 | LED2，经 330 Ω 限流电阻 |
| 4 | 7 | PA3 | LED3，经 330 Ω 限流电阻 |
| 5 | 9 | PC3 | LED4，经 330 Ω 限流电阻 |
| 6 | 11 | PC0 | 外接按键 1，按下接 GND |
| 7 | 13 | PA12 | 外接按键 2，按下接 GND |

内侧偶数列继续保留，独立 PWM 使用 `P5-14 / PA11 / TIM1_CH4 / AF1`。PA11、PA12同时连接开发板 USB HOST/USB SLAVE 数据线；采用上述分配时只能使用板载 `USB_UART` Type-C 串口，不能使用 USB HOST 或 USB SLAVE 接口。

MAX7219 三根控制线移到内侧偶数列，与 LED/按键完全分开：

| P5 引脚 | MCU 网络 | 用途 |
|---:|---|---|
| 2 | PB12 | MAX7219 DIN，经 74AHCT125 电平转换 |
| 6 | PE0 | MAX7219 LOAD，经 74AHCT125 电平转换 |
| 8 | PA2 | MAX7219 CLK，经 74AHCT125 电平转换 |

LED 接法：`MCU 引脚 -> 330 Ω~1 kΩ 电阻 -> LED 正极`，LED 负极统一接 GND。软件为高电平点亮。

按键接法：外接按键 1 一端接 PC0/P5-11，外接按键 2 一端接 PA12/P5-13；另一端都接 GND。软件开启内部上拉，因此按下为低电平，不另接 3.3 V。

### 数码管定稿电路

说明书已经确认数码管为 `FJ5463A`、四位、共阴极。不得把 12 个引脚直接接 MCU，也不得使用面向共阳数码管的 TM1637 电路。本工程采用 `MAX7219 + 74AHCT125`：MAX7219 负责恒流与扫描；74AHCT125 把 STM32 的 3.3 V 控制信号可靠转换成 MAX7219 所需的 5 V 逻辑。

电源从原理图明确标出的 ATK MODULE 接口 `U3-6(VCC5)` 和 `U3-5(GND)` 取得。转接板 P5-1 的 GND 也必须接入同一个 GND。不要在 U3 上同时插其他 ATK 模块。

74AHCT125（14 引脚）连接：

| 74AHCT125 引脚 | 连接 |
|---:|---|
| 14 | VCC5 |
| 7 | GND |
| 1、4、10（前三路 /OE） | GND，始终使能 |
| 2 -> 3 | PB12/P5-2 输入，3 脚输出到 MAX7219-1(DIN) |
| 5 -> 6 | PA2/P5-8 输入，6 脚输出到 MAX7219-13(CLK) |
| 9 -> 8 | PE0/P5-6 输入，8 脚输出到 MAX7219-12(LOAD) |
| 13、12、11（未用第四路） | 13 接 VCC5、12 接 GND、11 悬空 |

MAX7219（24 引脚）基础连接：`19=VCC5`，`4、9=GND`，`18(ISET)` 通过 `33 kΩ` 接 VCC5，`24(DOUT)` 悬空；芯片附近 VCC5-GND 并联 `0.1 µF 陶瓷电容 + 10 µF 电解电容`。

MAX7219 到 FJ5463A 的一一连接：

| MAX7219 | FJ5463A 引脚及含义 |
|---|---|
| 14 SEG A | 11（A） |
| 16 SEG B | 7（B） |
| 20 SEG C | 4（C） |
| 23 SEG D | 2（D） |
| 21 SEG E | 1（E） |
| 15 SEG F | 10（F） |
| 17 SEG G | 5（G） |
| 22 SEG DP | 3（小数点） |
| 2 DIG0 | 6（DIG4，最右位） |
| 11 DIG1 | 8（DIG3） |
| 6 DIG2 | 9（DIG2） |
| 7 DIG3 | 12（DIG1，最左位） |

MAX7219 的 DIG4～DIG7（3、10、5、8 脚）不连接。FJ5463A 从正面看，左下为 1 脚，沿外框逆时针编号；焊接前必须再按说明书的正视方向核对一次。

## 4. DAP 与串口

DAP 下载只需：SWDIO、SWCLK、GND、VTref/3.3V，建议再接 NRST。不要再并接 ST-LINK。

串口有两种方式，只选一种：

1. 使用开发板板载 USB 转串口：连接开发板 `USB_UART` Type-C，并保留 PA9/PA10 与 CH340 的跳线帽。
2. 使用 DAP 的虚拟串口 COM9：DAP-RX 接 PA9/P5-21，DAP-TX 接 PA10/P5-22，GND 共地；应取下连接板载 CH340 的两只串口跳线帽，避免两个 TX 输出并接。

## 5. 重要限制和未完成的实物验证

- 数码管型号、共阴极属性及 12 个脚位已经根据 `D:\MiniPro_H750\商品说明书.pdf` 和 `商品说明书 下.pdf` 确认；MAX7219 转接板尚未焊接，因此当前只能确认代码编译和接口分配正确，不能宣称数码管实物已点亮。
- 最新固件已用 CMSIS-DAP 完成 `Erase / Programming / Verify OK / Application running`。屏幕图像仍需操作者肉眼确认；看到 `NECCS H750 BASE` 后再记为屏幕实物通过。
- 4.3 寸 TFTLCD 电流较大，开发板应由自己的 USB/5 V 口供电；DAP 的 3.3 V/VTref 只用于目标电平参考，不用于给整板和屏幕供电。
- P4 的 PD/PE 引脚已被 TFTLCD 的 FMC 总线占用，不能再分配给外接板。
- PA8 已连接板载红外接收头，不作为 PWM 输出使用。
- 使用本转接板时，不要再插无线模块或 ATK 串口模块；它们与 PB14/PB15、PA2/PA3、PC0/PC3、PE0 等引脚复用。
- PA11/PA12 用作 PWM 和外接按键时，不得连接开发板的 USB HOST/USB SLAVE；板载 USB_UART 串口不受影响。
